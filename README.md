# Tic Tac Toe Game

This is a simple implementation of the classic Tic Tac Toe game built with HTML, CSS, and JavaScript. You can play against another player on the same device.

## Demo

You can try out the game online here: [https://pranav-94.github.io/Tic-Tac-Toe/](https://pranav-94.github.io/Tic-Tac-Toe/)

## Features

- Simple and intuitive user interface.
- Responsive design for mobile and desktop.
- Prevents invalid moves (clicking on occupied cells).
- Win detection (horizontal, vertical, diagonal).
- Draw detection.
- Restart game functionality.

## How to Play

1.  Open the game in your browser using the demo link or by running it locally.
2.  The first player is typically 'X', and the second is 'O'.
3.  Click on any empty square on the 3x3 grid to place your mark.
4.  Players alternate turns.
5.  The game ends when one player gets three of their marks in a row (horizontally, vertically, or diagonally) or when all squares are filled (resulting in a draw).
6.  Click the "Restart Game" button to start a new game at any time.

## Getting Started

To get a local copy up and running, follow these simple steps.

1.  Clone the repository:
    ```bash
    git clone https://github.com/pranav-94/Tic-Tac-Toe.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd Tic-Tac-Toe
    ```
3.  Open the `index.html` file in your preferred web browser.
