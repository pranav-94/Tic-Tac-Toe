## Demo

You can try out the game online here: [https://pranav-94.github.io/Tic-Tac-Toe/](https://pranav-94.github.io/Tic-Tac-Toe/)

## Features

- Simple and intuitive user interface.
- Play against another player locally.
- Responsive design for mobile and desktop devices.
- Prevents invalid moves (e.g., clicking on an occupied cell).
- Game win/draw detection and announcement.
- Option to restart the game.

## Installation

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/pranav-94/Tic-Tac-Toe.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Tic-Tac-Toe
    ```
3.  No further installation is required as it's a front-end project.

## Usage

1.  Open the `index.html` file in your web browser.
2.  The game board will appear.
3.  Player 1 (X) goes first, then Player 2 (O).
4.  Click on an empty cell to place your mark.
5.  The game will announce the winner or if it's a draw.
6.  Click the "Restart Game" button to play again.
