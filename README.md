# Tic Tac Toe Game

This is a simple implementation of the classic Tic Tac Toe game in JavaScript.  You can play against another player.

## Demo

You can try out the game online here: [https://pranav-94.github.io/Tic-Tac-Toe/](https://pranav-94.github.io/Tic-Tac-Toe/)


## Features

- Simple and intuitive user interface.
- Responsive design for mobile and desktop.
- Prevents invalid moves (e.g., placing a mark on an occupied square).
- Detects win conditions for both players and draws.
- Clear visual indication of the current player's turn.
- Option to restart the game easily.


## Technology Stack
