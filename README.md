# Tic Tac Toe Game

This is a simple implementation of the classic Tic Tac Toe game in JavaScript. You can play against another player.

## Table of Contents

- [Demo](#demo)
- [Features](#features)
- [How to Play](#how-to-play)

## Demo

You can try out the game online here https://pranav-94.github.io/Tic-Tac-Toe/ .

## Features

- Simple and intuitive user interface.
- Responsive design for mobile and desktop.
- Prevents invalid moves (clicking on occupied cells).
- Announces the winner or a draw.
- Option to reset the game.

## How to Play

1.  Open the game in your web browser using the demo link or by running it locally.
2.  The game board is a 3x3 grid.
3.  Player 1 is 'X' and Player 2 is 'O'.
4.  Players take turns clicking on an empty cell to place their mark.
5.  The first player to get three of their marks in a horizontal, vertical, or diagonal row wins the game.
6.  If all cells are filled and no player has won, the game is a draw.
7.  Click the "Reset Game" button to start a new game at any time.
