## Features

- Simple and intuitive user interface.
- Play against another player (two-player mode).
- Responsive design for mobile and desktop devices.
- Prevents invalid moves (clicking on an already occupied square).
- Announces the winner or a draw.
- Option to reset the game.

## How to Play

1.  The game board is a 3x3 grid.
2.  Player 1 is 'X' and Player 2 is 'O'.
3.  Players take turns clicking on an empty square to place their mark.
4.  The first player to get three of their marks in a horizontal, vertical, or diagonal row wins the game.
5.  If all nine squares are filled and no player has three marks in a row, the game is a draw.
6.  Click the "Reset Game" button to start a new game at any time.
