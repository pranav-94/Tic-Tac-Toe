## Features

- Simple and intuitive user interface.
- Play against another player locally.
- Responsive design for mobile and desktop devices.
- Prevents invalid moves (e.g., clicking on an occupied cell).
- Announces the winner or a draw.
- Option to reset the game.

## Installation

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/pranav-94/Tic-Tac-Toe.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Tic-Tac-Toe
    ```
3.  **Open the `index.html` file:**
    Simply open the `index.html` file in your preferred web browser. No web server is required.

## How to Play

1.  Open the game in your browser (either via the demo link or by opening `index.html` locally).
2.  The game board will be displayed.
3.  Player 1 (X) goes first. Click on any empty cell to place your 'X'.
4.  Player 2 (O) goes next. Click on any empty cell to place your 'O'.
5.  Players take turns placing their mark in an empty cell.
6.  The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins.
7.  If all nine cells are filled and no player has won, the game is a draw.
8.  A message will appear indicating the result.
9.  Click the "Restart Game" button to play again.
