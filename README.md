# Tic Tac Toe Game

This is a simple implementation of the classic Tic Tac Toe game built with HTML, CSS, and JavaScript. You can play against another player on the same device.

## Demo

You can try out the game online here: [https://pranav-94.github.io/Tic-Tac-Toe/](https://pranav-94.github.io/Tic-Tac-Toe/)

## Features

- Play against another human player.
- Simple and intuitive user interface.
- Responsive design for mobile and desktop.
- Prevents invalid moves (clicking occupied cells).
- Game win/draw detection.
- Option to restart the game.

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

To run this project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/pranav-94/Tic-Tac-Toe.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd Tic-Tac-Toe
    ```
3.  Open the `index.html` file in your web browser.

## Usage

Simply open the `index.html` file in your browser (or access the demo link). Click on an empty cell to make your move. The game will indicate whose turn it is and announce the winner or a draw. Click the "Restart Game" button to start a new game.
