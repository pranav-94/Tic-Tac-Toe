## Features

*   **Two-Player Mode:** Play head-to-head against another player.
*   **Intuitive UI:** Clean and easy-to-understand interface.
*   **Responsive Design:** Play seamlessly on desktop, tablets, and mobile devices.
*   **Invalid Move Prevention:** Clicking on an already occupied cell is not allowed.
*   **Win/Draw Detection:** Clearly indicates when a player wins or the game ends in a draw.
*   **Reset Functionality:** Easily start a new game.

## Installation

This is a front-end only project. To run it locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/pranav-94/Tic-Tac-Toe.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd Tic-Tac-Toe
    ```
3.  Open the `index.html` file in your web browser.

## How to Play

1.  Open the game in your browser (either via the demo link or by opening `index.html` locally).
2.  Player 1 (X) goes first.
3.  Click on any empty cell on the 3x3 grid to place your mark (X or O).
4.  Players take turns placing their marks.
5.  The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins.
6.  If all cells are filled and no player has won, the game is a draw.
7.  Click the "Reset Game" button to start a new game at any time.
