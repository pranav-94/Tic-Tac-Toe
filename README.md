You can try out the game online here https://pranav-94.github.io/Tic-Tac-Toe/ .

## Features

- Simple and intuitive user interface.
- Responsive design for mobile and desktop.
- Prevents invalid moves (clicking on occupied squares).
- Indicates the current player.
- Declares the winner or a draw.

## Installation

To run this game locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/pranav-94/Tic-Tac-Toe.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Tic-Tac-Toe
   ```
3. Open the `index.html` file in your web browser.

## How to Play

1. The game is played on a 3x3 grid.
2. Two players take turns marking a square with their symbol (X or O).
3. The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins the game.
4. If all nine squares are filled and no player has three marks in a row, the game is a draw.
5. Click on an empty square to make your move.
