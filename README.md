## Features

- Prevents invalid moves (clicking occupied cells).
- Detects win conditions (rows, columns, diagonals).
- Detects draw conditions.
- Allows resetting the game.

## Setup

To run this project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/pranav-94/Tic-Tac-Toe.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd Tic-Tac-Toe
    ```
3.  Open the `index.html` file in your preferred web browser.

## How to Play

1.  The game is played on a 3x3 grid.
2.  Two players take turns marking a cell with their symbol ('X' or 'O').
3.  Click on an empty cell to place your mark.
4.  The first player to get three of their marks in a horizontal, vertical, or diagonal row wins the game.
5.  If all nine cells are filled and no player has three marks in a row, the game is a draw.
6.  Click the "Restart Game" button to start a new game.
