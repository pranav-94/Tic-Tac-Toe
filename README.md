## How to Play

1.  The game is played on a 3x3 grid.
2.  Two players take turns marking a square with their symbol (typically 'X' and 'O').
3.  The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins the game.
4.  If all nine squares are filled and no player has three marks in a row, the game is a draw.
5.  Click on an empty square to place your mark.
6.  The game will indicate whose turn it is.
7.  After a game ends (win or draw), you can typically start a new game.

## Features

- Classic 3x3 grid gameplay.
- Two-player mode (local).
- Clear indication of the current player.
- Win and draw detection.
- Prevents marking occupied squares.
- Simple and responsive user interface.
